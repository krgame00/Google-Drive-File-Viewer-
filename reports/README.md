# รายงานและข้อมูลประกอบ

โฟลเดอร์นี้มีทั้งไฟล์ที่ Git ติดตามอยู่แล้วและผลลัพธ์ในเครื่อง กฎ `reports/*` ใน `.gitignore` ละเว้นไฟล์ใหม่ ยกเว้นคู่มือ `README.md` แต่ไม่ได้หยุดติดตามไฟล์เดิม

## ไฟล์ที่ติดตามใน Git

| ไฟล์ | หน้าที่ |
| --- | --- |
| `drive_alive_report.json` | ผลตรวจ Drive; เป็นอินพุตของ `scripts/data/patch_alive_from_report.py` |
| `mega_alive_report.json` | ผลตรวจสถานะ MEGA |
| `drive_mega_map.json` | ข้อมูลจับคู่ Drive กับลิงก์อื่น เป็นอินพุตและข้อมูลที่บางสคริปต์ปรับแก้ |

อย่าลบ `drive_mega_map.json` เหมือนรายงานชั่วคราว เพราะไม่ใช่ผลตรวจที่สร้างใหม่ได้โดยไม่ต้องมีข้อมูลต้นทาง

## ผลลัพธ์ในเครื่อง

เช่น `drive_names_report.json`, `*_detail.json`, `sizes_*.json`, `sizes_report.txt`, `dead_ids.txt` และ `ids_*.txt` บางไฟล์เป็นอินพุตให้ขั้นตอนถัดไปด้วย ตรวจการอ้างอิงในสคริปต์ก่อนล้าง

รายงานอธิบายการทดสอบสำหรับคนอ่านอยู่ใน `docs/test-report-*.md` ส่วนที่นี่เก็บข้อมูลรายงานของเครื่องมือ การจัดครั้งนี้ยังไม่ย้ายหรือลบข้อมูลรายงานเดิม
