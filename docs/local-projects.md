# บันทึกการล้างโฟลเดอร์ที่ไม่ใช้ในเว็บหลัก

วันที่ 2 ตุลาคม 2026 ผู้ใช้ยืนยันให้ลบโฟลเดอร์ต่อไปนี้ถาวร รวมไฟล์ตั้งค่าของแอป Gemini:

| โฟลเดอร์ | เนื้อหาที่ลบ |
| --- | --- |
| `gemini-chatbot/` | แอป chatbot แยก รวม dependencies และ `.env` |
| `DriveViewer-Portable/` | ชุดเว็บ Portable แยกและบันทึกไฟล์ว่าง |
| `sketches/` | ต้นแบบหน้าเว็บและคู่มือของแบบทดลอง |
| `test-media/` | คลิปตัวอย่าง สำเนาเครื่องเล่นรุ่นก่อน และคู่มือ |

ก่อนลบตรวจว่าตำแหน่งทั้งหมดอยู่ภายใน workspace และไม่มี symbolic link/junction รวมถึงไม่พบจุดเรียกใช้จากเว็บหลัก สคริปต์เครื่องมือ ชุดทดสอบ และ GitHub Actions

โฟลเดอร์เหล่านี้ไม่ได้ถูกติดตามใน Git ก่อนลบ จึงไม่สามารถใช้ Git ของโปรเจกต์นี้คืนเนื้อหาที่ลบไปได้

ยังคงไฟล์เว็บหลัก Service Worker ซอร์ส Cloudflare ข้อมูลคลัง รายงาน สคริปต์ ชุดทดสอบ และเอกสารของระบบ Drive viewer ไว้ครบ
