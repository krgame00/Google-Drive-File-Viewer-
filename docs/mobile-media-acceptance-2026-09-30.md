# ผลทดสอบเครื่องเล่น/ภาพบนมือถือ — 2026-09-30

> เอกสารหลักฐานตามแผน `docs/superpowers/plans/2026-09-30-mobile-media.md` ช่วง 2
> **หลักการ:** ผลจากชุดทดสอบจำลอง (Node VM) ไม่ถือเป็นผลทดสอบอุปกรณ์จริง — ช่องที่ยังไม่ได้ลองบนเครื่องจริงต้องทดสอบก่อนถือว่าผ่าน
> **ห้ามบันทึก:** OAuth token, อีเมล/ข้อมูลบัญชีส่วนตัว ลงในเอกสารนี้

## ข้อมูลการทดสอบ (กรอกเมื่อทดสอบจริง)

| หัวข้อ | ค่า |
|---|---|
| วันที่ทดสอบ | ยังไม่ได้ทดสอบ |
| Commit ที่ทดสอบ | (ระบุ hash จาก `git rev-parse --short HEAD`) |
| Browser หลัก | ยังไม่ได้ทดสอบ (เป้าหมาย: Brave Android — ระบุเวอร์ชันจาก brave://version) |
| Browser เปรียบเทียบ | ยังไม่ได้ทดสอบ (Chrome Android) |
| Safari iPhone | ยังไม่ได้ทดสอบ (ทดสอบเมื่อมีอุปกรณ์จริงเท่านั้น) |
| Android/iOS เวอร์ชัน | ยังไม่ได้ทดสอบ |
| Viewport | ยังไม่ได้ทดสอบ (เช่น 390×844) |
| สถานะบัญชี | ยังไม่ได้ทดสอบ (ล็อกอิน / ไม่ล็อกอิน — ระบุแต่ละเคส) |
| เครือข่าย | ปกติ / จำกัดความเร็ว (จำลองด้วย DevTools throttling บนเครื่องจริงไม่ได้ ให้ใช้สัญญาณจริงอ่อน) |

## คลิป/ไฟล์ทดสอบ

- [ ] MP4 ขนาดเล็กที่มีสิทธิ์เข้าถึง (ใช้ไฟล์ทดสอบทั่วไป ไม่ละเอียด)
- [ ] MP4 ขนาดใหญ่ (ทดสอบ seek ข้ามช่วง)
- [ ] วิดีโอแนวตั้ง
- [ ] ข้อผิดพลาดจำลอง quota/permission: ใช้ไฟล์ที่บัญชีทดสอบ**ไม่มีสิทธิ์** (ไม่ใช่การยิงจนโควตาจริง)

## สรุป

- ชุดทดสอบจำลอง (Node): ผ่านทั้งหมดตามที่รายงานในโค้ด — **แต่ไม่ถือเป็นผลทดสอบอุปกรณ์จริง**
- Brave Android จริง: **ยังต้องทดสอบ** — กรอกตารางข้างบนให้ครบก่อนถือว่าตรวจรับผ่าน
- ข้อจำกัดที่ทราบ: การสตรีมขึ้นกับสิทธิ์ดาวน์โหลด/โควตาของ Google และ codec ที่เบราว์เซอร์รองรับ; พรีวิว Google ใช้บัญชีแยกจากที่เชื่อมต่อในเว็บ
